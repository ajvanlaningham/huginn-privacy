Privacy Policy

Huginn — a self-hosted, single-user personal automation application

Effective date: November 5, 2026

Overview and Purpose

Huginn is a self-hosted personal automation application operated by a single user on private homelab infrastructure. This privacy policy explains how Huginn handles information when it connects to third-party services (such as Google) on behalf of its sole operator.

Huginn is not a multi-tenant service. It is not offered to the public, has no user accounts for anyone other than its owner, and does not process data belonging to any other person or organization.

Scope

This policy applies to the Huginn instance operated by the owner identified in the Contact section below. It covers OAuth tokens and any data retrieved from authorized third-party APIs for the purpose of running personal automations.

Information We Collect

Huginn only handles data that is necessary for its owner's personal automations:

  • OAuth access and refresh tokens issued by third-party providers (e.g. Google) after the owner grants consent.
  • API responses retrieved using those tokens, limited to the scopes the owner has approved.

Huginn does not collect data from any other person. No visitor to this privacy policy page is tracked, profiled, or asked to provide personal information.

How Information Is Used

Information is used solely to execute the owner's own automations — for example, reading messages, scheduling tasks, or moving files between services that the owner personally uses. Data is never processed on behalf of anyone else.

Data Sharing and Selling

No data is sold, rented, traded, or shared with any third party. There are no advertisers, analytics providers, data brokers, or marketing partners involved. Information remains between the owner's self-hosted Huginn instance and the provider that issued the token.

Data Storage and Security

OAuth tokens and any cached API data are stored locally on the owner's private homelab infrastructure. There is no cloud database, no hosted backend, and no managed service in front of Huginn.

Security measures

  • Tokens are kept on hardware physically controlled by the owner.
  • Network access to Huginn is restricted to the owner's private network.
  • Secrets are not committed to source control and are not transmitted to external systems.

Data Retention and Deletion

Tokens are retained only as long as they are useful for the owner's automations and can be revoked at any time through the issuing provider's account settings (for Google data, via Google Account permissions). Revoking access immediately invalidates the token on Huginn's side.

Use of Google User Data

Huginn's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained from Google APIs is used only to provide the owner's personal automations and is never transferred to others, used for advertising, or read by humans except as needed for security, debugging, or when the owner explicitly chooses to view it.

Children's Privacy

Huginn is a single-user personal tool and is not directed to children. No data about children is knowingly collected or processed.

Changes to This Policy

If this policy changes, the updated version will be published at the same URL and the effective date at the top of the page will be revised. There is no mailing list or notification system; the published page is the single source of truth.
